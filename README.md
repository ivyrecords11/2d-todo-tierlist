# 2d-todo-tierlist
2-dimensional (Urgency, Importancy) tierlist of mixed goals

https://ivyrecords11.github.io/2d-todo-tierlist/

## Editing

The GitHub repository is the source for the Pages site. Edit `index.html`,
`styles.css`, and `app.js`, then commit and push to `main` to publish changes.
There is no build step.

Boards and images are stored in each browser's IndexedDB. They are not part of
the Git repository, so opening the Pages URL in another browser starts with an
empty board.
